# Carpeta de Documentos

Esta carpeta contiene documentos descargables del sitio web de Norttek Solutions.

## Archivos requeridos:

### SAT.pdf
- **Descripción**: Constancia de Situación Fiscal
- **Ubicación**: `assets/documents/SAT.pdf`
- **Uso**: Se descarga desde la página de cuentas (`cuentas.php`)
- **Formato**: PDF
- **Tamaño recomendado**: Máximo 2MB

## Instrucciones:

1. Colocar el archivo `SAT.pdf` en esta carpeta
2. Verificar que el nombre del archivo sea exactamente `SAT.pdf`
3. Asegurarse de que el archivo tenga permisos de lectura

## Nota de Seguridad:

Los documentos en esta carpeta son accesibles públicamente. 
No colocar documentos con información sensible o confidencial.
