🔍 Verificador de Versión de cuentas.js

Instrucciones:

  1. Abre http://localhost/norttek.com.mx/cuentas.php
  2. Abre la Consola del Navegador (F12 → Console)
  3. Busca el mensaje: 🔄 Cuentas.js v2.0 - WhatsApp Integration CARGADO

✅ Si ves el mensaje v2.0:

La nueva versión se cargó correctamente. El botón "Compartir" debería abrir el modal de WhatsApp.

❌ Si NO ves el mensaje v2.0:

El navegador sigue usando cache. Intenta:

  • Chrome/Edge: Ctrl + Shift + Delete → Borrar caché
  • Firefox: Ctrl + Shift + Delete → Caché
  • Modo incógnito: Ctrl + Shift + N
  • Desactivar caché: F12 → Network → Disable cache

🔗 URL del archivo JS con versión:

El sistema ahora carga automáticamente con parámetro de versión:

assets/js/cuentas.js?v=
